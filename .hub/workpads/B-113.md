   `.sdp-package` and `.ms_package_ownership_bytes()` returns
   `charToRaw("sdp-owned\n")`. Nothing else names the file, so the writer,
   `.ms_package_managed_paths()`, the pre-read containment list and
   `.ms_is_metasalmon_package_dir()` all name only the shared file, and no
   per-language sentinel is written. The comment on the helpers says why there

   old sentinel. The `overwrite` roxygen text of `write_salmon_datapackage()`
   and `create_sdp()` says what is recognised now, and the emptiness comment in
   `.ms_check_package_write_dir()` names the new file.

   `devtools::document()`. This machine's roxygen2 is 8.1.0 against the
   recorded 8.0.0, and it rewrote `NAMESPACE` and the recorded version, so
   both were restored and only the two Rd files are in the change.
3. **`tests/testthat/test-package-ownership-sentinel.R`, new.** Four tests, 20
   expectations. The name and content line are pinned as literals rather than
   read back from the helpers, because a pin that reads the value it pins
   passes whatever the value is. They pin: both literals and the bytes a real
   write puts on disk, with every dot-file at the package root listed so a
   per-language sentinel under any name would fail it; that a directory
   carrying only `.sdp-package` is recognised as owned and can be written with
   `overwrite = TRUE`; that one carrying only `.metasalmon-package` or only
   `.metasalmonpy-package` is not, and is left untouched (the break Q14
   accepted); and that the managed-path inventory names only the shared file,
   so a rewrite leaves both per-language sentinels exactly as they were
   (neither writer removes the other's file, and nothing migrates one).
4. **`tests/testthat/test-package-helpers.R`.** Its ten sites that wrote or
   checked `.metasalmon-package` as a literal now go through the helpers: eight
   fixtures, and the two assertions that a rewrite keeps the sentinel. The Q15
   near-miss test is renamed from "a stale metasalmon sentinel" to "a stale
   ownership sentinel" and writes the helper's bytes; its header comment names

5. **`NEWS.md`.** A `### Breaking changes` entry under the development

6. **`knowledge/parity-deviations.md`.** Row 51 records the name, the reasons,
