# B-121 — Reconstruct the smn PR #27 amendment literals

## Change

`proposals/smn_pr27_definition_amendments.ttl` is a proposed replacement set
for seven existing PR #27 subject-predicate literals. It is an input to
review, not a graph to union with the PR and not a change to the ontology
branch. Its header pins PR #27 at `949ed9528a173f739ad0d74ad8e93bb0ae4cef55`
and the commons at `18463e3` and gives the replacement rule. Three sockeye
definitions are drawn from the current corrected commons card. Two source
annotations remove the unsupported attribution of the river-type one-to-two
year range to Beacham and Withler 2017 or DFO SAR 2022/003. Two cycle-line
scope notes correct the claim that the term was coined by this vocabulary and
the claim that pink broodlines are absolutely closed.

The 2026-09-02 pass produced four commons cards: the
[sockeye definition set](https://github.com/salmon-data-mobilization/salmon-knowledge-commons/blob/18463e3/concepts/sockeye-life-history-type-definitions.md)
and [pink line definition set](https://github.com/salmon-data-mobilization/salmon-knowledge-commons/blob/18463e3/concepts/pink-salmon-line-definitions.md)
inform these smn literals. The [management-level card](https://github.com/salmon-data-mobilization/salmon-knowledge-commons/blob/18463e3/concepts/fishery-reference-points-and-management-levels.md)
and [quality-framework card](https://github.com/salmon-data-mobilization/salmon-knowledge-commons/blob/18463e3/concepts/spsr-data-quality-frameworks.md)
concern gcdfo holds #84/#85 and yield no PR #27 replacement. The cards have
in-card citation tables; the separate citation-verification CSV once attributed
to the pass remains unwritten. B-122 corrected the Gilbert 1913 read: the term
appears in five species sections, so PR #27's five-species wording is left
alone.

The S9 card, roadmap, and Foundry plan link the later reconstruction and keep
the 2026-09-10 finding that the named file had never been made at that time.
The proposal lives outside `knowledge/`, whose OKF capture validator rejects
static Turtle assets, and `.Rbuildignore` excludes it from the R package.

## Verification

- Before the change, the named Turtle file was absent and S9 and the Foundry
  plan contained present-tense claims that it did not exist.
- `rdflib` parsed seven triples. For each, PR #27's pinned source graph has
  exactly one different English literal for the same subject and predicate.
  Both generic `OddYearCycleLine` and `EvenYearCycleLine` remain untouched.
- All three updated Markdown documents have live relative links to the
  proposal. `psc-okf check knowledge --tier capture` passed with zero
  diagnostics after the Turtle file moved outside the checked bundle.
- A first OKF run rejected `knowledge/data/*.ttl` as an unsupported bundle
  asset; the final layout avoids that failure without changing OKF policy.
- `R CMD build .` passed. The source tarball contains `DESCRIPTION` and no
  `proposals/` path, confirming that the review-only Turtle is excluded from
  the package. `git diff --check` passed.

## Review boundary

Q-06 still owns the six remaining modelling rulings, including peerhood and
scope. The pink card proposes pink-specific broodline definitions, while PR
#27's odd/even cycle-line terms cover any two-year-cycle population; this
artifact does not substitute one for the other. The proposal must be reviewed
and applied to the smn branch before the Foundry briefing freezes a PR snapshot.
There is no metasalmon package behavior to port to metasalmonpy.
