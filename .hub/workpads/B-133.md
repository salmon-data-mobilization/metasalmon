# B-133 — Stop two display-only vignettes from tangling as live R

## Change

`vignettes/migrating-to-sdp-0-3-0.Rmd` and
`vignettes/tidy-data-for-sdp.Rmd` now mark their 18 and 7 illustrative R
chunks `purl = FALSE` individually. The setup chunks still set global
`eval = FALSE` for rendered examples. Purled setup alone would not fix the
problem: the tangle does not execute it, and the guard has a fixture proving
that case still fails.

`tests/testthat/test-vignette-purl-guard.R` removes the two B-133 known-offender
entries after their fixes and retains an empty register for future pinned
exceptions. Its comments and the development NEWS entry now reflect the fix.
No R package runtime code or ontology term changed; metasalmonpy guide
behaviour needs no mirror change.

## Verification

- Before editing, direct `knitr::purl()` of the two vignettes yielded 50 and
  18 executable expressions, respectively; a zero-expression assertion failed.
- After marking the 25 chunks but before removing the exceptions, the focused
  guard failed on both stale known-offender entries. This is the guard's
  intended signal that an exception cannot outlive its defect.
- After removal, direct `knitr::purl()` yielded zero expressions for both.
  `testthat::test_file("tests/testthat/test-vignette-purl-guard.R",
  stop_on_failure = TRUE)` passed.
- `_R_CHECK_VIGNETTES_SKIP_RUN_MAYBE_=false Rscript -e
  'rcmdcheck::rcmdcheck(args = "--no-manual", error_on = "warning")'` passed on
  local R 4.5.2: zero errors, warnings or notes. The check printed its
  `running R code from vignettes` step and marked both repaired guides OK.
  R 4.3.3 is not installed here; its formerly failing step was exercised under
  the explicit override on R 4.5.2, and CI will supply the current-R check.
- `Rscript scripts/build-pkgdown.R` initially stopped before building because
  checked-in `docs/pkgdown.yml` pins Pandoc 3.8.3 and this shell has 3.11.
  Re-running with the previously cached official 3.8.3 binary completed.
  It also regenerated many unrelated stale site pages, favicons and reference
  pages from earlier work, so all generated `docs/` changes were discarded;
  this branch commits source vignettes and NEWS, not an unrelated site rebuild.
- `git diff --check` passed.

## Boundary

The pinned-exception list is empty. The guard's own retirement condition remains:
CI must run its real vignette-code step. Until then it checks the tangle in the
test suite even when current R versions skip that step by default. No new skip,
allowlist entry or suppression was added.
