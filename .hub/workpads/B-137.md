## Boundary and follow-up

This B-137 claim covers metasalmon only. No Python runtime change is needed:
its `metadata.R_SPACE_CLASS` already contains the non-ASCII members used here.
The Python `PARITY.md` row 28 and `metadata.py` explanation still describe R's

row numbers, not description truth.

with `values <- c(clean = "http://example.org/ab", ideographic =
paste0("http://example.org/a", intToUtf8(0x3000L), "b"), figure =

`.ms_sssom_is_absolute_uri()` returns `TRUE, FALSE, TRUE` under both C and

`[[:space:]]` patterns in `R/sssom.R` do not use the shared predicate. I
searched the queue's SSSOM items, including B-269/B-270 and B-86; none covers
this locale-dependent path. It is outside B-137's six named failures.

The Unicode print-test skip retires when that assertion compares output in a
locale-independent representation or `print()` emits the same bytes under a
non-UTF-8 locale. It preserves the exact-output assertion wherever the console
can print Unicode without escaping it.
