# B-186 — Reject stream references that name no queue stream

## Changes

`scripts/hub_queue.py` derives canonical stream names from parsed `kind: stream`
S-items and rejects unknown or padded references as `stream-missing`.
`scripts/tests/test_hub_queue.py` demonstrates rejection of S05 and S99,
acceptance of S5 and a newly added S-99, and preservation of optional/empty
values. Completed streams remain valid identities. NEWS records the lint change.

## Verification

- Before the fix, the two new rejection cases fail: the linter accepts them.
- After the fix, all three focused cases pass and all 164 offline queue tests
  pass. The live queue lint passes on 318 items.
- `git diff --check`: pass. NEWS uses the helper branch's NEWS-only build
  under pinned pkgdown/Pandoc; only this item’s generated fragment is retained.

## Scope

No package runtime, ontology term, claim protocol or Python package capability
changes. A stricter rule rejecting completed streams was not chosen: identity
references remain meaningful after completion, and B-186 requires existence.
No other defect was absorbed.

## Guards and retirement

No suppression or workaround added. The new validation is needed while stream
references use a separate unpadded label; it retires if the queue schema removes
that field or references stream item IDs directly.
