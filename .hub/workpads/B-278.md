## Contract

`detect_semantic_term_gaps(commons_gaps = "gaps.json")` accepts only the JSON
export file path, mutually exclusive with dictionaries and suggestions. SDP
filters must keep their defaults. Its existing 33-column prefix retains the
original column names/types; unknown dataset/role/candidate/LLM evidence stays
missing. Source records retain order and duplicates, followed by all fifteen
emitted fields prefixed `commons_`, plus `commons_hold_reason`.

The reader rejects malformed envelopes, records, types, enums and lifecycle
conditions. `blocked_by` is a JSON array, not a scalar or null; `verified` is a
boolean. Proposed/rejected lifecycle requirements remain intact, and minted
entries are forbidden by the commons schema. No live source lookup occurs.

The renderer recomputes holds from source fields rather than trusting the
display string or placement recommendation. Ordered hold reasons are
`proposed`, `rejected`, `do-not-mint`, `blocked`, `conflicted`, `contested`,
`evidence-needed`, `unsupported-target`, `deprecated-card`, joined by `; `.
Only open, unheld, explicit SMN/GCDFO rows receive a new request route.
`scope`, `scope_overrides` and `ask` neither revive nor redirect these rows.
All held rows remain visible. Draft/unverified cards may generate drafts but
do not imply verification or approval. Bodies preserve the concept identifier
and exact draft gap note, and require curator definition/type choices. They
claim no dataset evidence. Dry run authenticates and publishes nothing.
