## Implementation

`R/eml-mapping-yaml.R` owns the non-evaluating sidecar read. The closure is
its only current caller; B-223 can reuse it without another detector. R yaml
silently discards unknown tags, exact-name handlers erase the local/standard
prefix distinction, and no public event iterator or generic tag handler exists.
The twelve standard SafeLoader types remain accepted, including declared
handle and verbatim URI forms.

For other tag candidates, the disposable probe inserts an undefined private
node property before the unchanged token. libyaml validates the original
token, then resolves that private handle before constructing a value. This
refuses reached tags even on unfinished local, named or verbatim collections,
without interpreting YAML values or evaluating expressions. Quotes, comments,
plain/block text and original tag/URI delimiters remain intact; the probe
handle is absent from every source occurrence, so an authored directive cannot
bind it. Directive-looking lines are consumed only in document preludes.
The final error classification uses libyaml's own undefined-handle diagnostic,
not a lexical bang-only refusal. Untouched real input loads with literal
`eval.expr = FALSE` after the probe.

At most two YAML parses occur per read, independent of literal bang count;
there is no size/count rejection. The source records retirement when yaml
exposes original tags or native unknown-tag refusal. URI-decoder warnings
and disposable probe signals do not replace the real parser: invalid escapes
and syntax errors before unreached tags retain the previous malformed-input
fallback. Reached unknown tags precede later syntax errors. The real read's
warnings/errors are unchanged.

`.ms_closure_mapping_paths()` rethrows only the specific tag-refusal class
before path resolution/render/install and keeps malformed/nonmapping/read
fallback. The public writer's atomic three-file installer is unchanged.

Primary API/source inspection: yaml's public `yaml.load` API and exact handler
lookup at <https://github.com/r-lib/yaml/blob/main/R/yaml.load.R> and
<https://github.com/r-lib/yaml/blob/main/src/r_ext.c#L151-L206>, plus the
internal parser event loop in `src/r_parse.c`. Installed yaml is 2.3.12; no
dependency change. Native runtime probes verify the private-handle signal,
including invalid-URI scanner precedence and later-document reach.

### Native directive-boundary correction

After the first independent peer pass, a valid quoted `%TAG` line closing on
a `#`-leading line exposed a regression in the pending-binding heuristic.
The closing line looked like a comment to that heuristic, so a later real
`---` activated a quoted binding. Two reader refusals, one known-core
preservation error and four public writer assertions demonstrated the defect
(3.936s). The intervening full run had already completed: 9276 passes, zero
failures/errors, 38 warnings and 6 skips in 96.444s. It is preserved as
superseded-source verification rework, not acceptance evidence. Strict
checking and publication were held.

The supported native discriminator uses only the preceding document segment
and its original directive prelude. It changes the leading keyword `%TAG`
to `%YAML` in disposable candidate lines, leaving all original quote, escape
and comment characters intact. A tag handle is not a YAML version: libyaml's
version-scanner diagnostic names the first genuine directive's source line.
Only definitions at or after that original candidate position are activated;
quoted candidates preceding the genuine prelude cannot supply bindings.
Whole-line `%TAG !` replacement was rejected after a separate known-core
preservation RED, because deleting the line's closing quote changed context.

One native proof is made per document boundary with a pending directive
group. Each original document segment is visited once, and its prelude can
be reused once; a 40-document source-byte control rejects quadratic
whole-sidecar re-parsing. The previous global at-most-two-parse statement is
therefore narrowed: ordinary literal-bang sidecars still use at most two
loads; directive groups also use these bounded segment proofs. The new third
YAML-call owner is in the evaluation guard's positive-control list and always
passes literal `eval.expr = FALSE`. Both disposable proofs retire with a
supported original-tag or native-refusal API in R yaml.
