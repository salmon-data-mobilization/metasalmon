Reader changes, so `read_sssom_mapping_set()` reads every file it writes: an
absent `curie_map` is an empty map (it was required), and a well-formed quoted
cell is unquoted (the spec's "MUST strip"). The quote-decoding versus
legacy-byte question B-432 left here is answered by decoding only a cell that
opens and closes with `"` and doubles every inner `"`; a legacy cell with a
bare inner quote reads byte for byte. `validate_sdp_sssom()` still accepts a
package in the earlier byte form (`still accepts a package in the
pre-canonical byte form`).

The B-233 test helper `sssom_test_canonical_text()` was already written in
the canonical form; the writer now reproduces it byte for byte from both it
and the legacy `sssom_test_text()`, in a UTF-8 session and under
`LC_CTYPE=C`. The `!expr` test (B-352) patched the writer's old quoted title
line and now patches the plain one.
