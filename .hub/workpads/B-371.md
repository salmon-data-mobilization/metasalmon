# B-371 — Guard two live GitHub tests with their actual request paths

## Change

`tests/testthat/test-github-helpers.R` now probes the public raw CSV without a
token before the no-token live test, using the B-152 raw-host guard. The
empty-directory test probes a known directory through `gh::gh()` at the GitHub
API with the configured token before it asks for the expected 404. The new API
probe uses the same contents endpoint, ref and token shape as
`read_github_csv_dir()`, but calls `gh::gh()` directly so a package bug remains
visible to the test. Off CI, a refused connection or API refusal skips; on CI,
the probe never skips and the test's own request remains strict.

No package runtime code changed. The metasalmonpy test sibling is B-372, a
separate queue item; this branch does not claim or alter it. This is test-only
network handling, so no NEWS or generated site change is needed.

## Verification

- RED before editing: with `NOT_CRAN=true`, `GITHUB_PAT` set to a dummy token,
  `CI` unset and `HTTPS_PROXY`/`HTTP_PROXY` pointing to closed local port 9,
  the focused file failed in exactly the two named tests. The B-152 guarded
  live tests skipped.
- GREEN with the same refused proxy and `CI` unset: the focused file passed;
  both named tests skipped after their matching probes failed. A deterministic
  regression pins the API probe's endpoint, ref and token and its off-CI skip.
- With the refused proxy and `CI=true`, the focused file failed at both named
  tests' own raw/API fetches. The API probe's deterministic regression also
  pins that it does not skip on CI. The existing token-configured directory
  fetch test still skips on its pre-existing API preflight in this setup; it
  is outside B-371's two named tests and was not changed.
- With normal network access, the focused file passed with `NOT_CRAN=true`
  under both unset `CI` and `CI=true`, including the genuine nonexistent
  directory's expected 404.
- `git diff --check` passed.

## Boundary and retirement

The new API skip retires when these live directory tests stop reaching the
GitHub API. The raw-host guard already names its own retirement condition.
Neither skip applies on CI. The Python sibling B-372 remains owed for its own
live GitHub test.
