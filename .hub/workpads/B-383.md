## Change

`R/llm-semantic-helpers.R` now sends `.Rmd` and `.qmd` through the existing
`.ms_read_text_utf8()` decoder before splitting lines, trimming front matter,
and removing code fences. That decoder validates UTF-8 and falls back to
Windows-1252, then Latin-1. The one call-site change is also reached by
`write_semantic_review_packet()` through `.ms_collect_context_chunks()` and
`.ms_context_text_from_file()`; it does not depend on the retiring in-package
model provider.

`tests/testthat/test-semantic-review-packet.R` writes an actual Windows-1252
Quarto file with a curly apostrophe, checks decoded UTF-8 and removal of front
matter and code fences, and checks that the same phrase appears in the
written packet's context excerpts. The test source uses Unicode escapes so
the R file remains ASCII. `NEWS.md` records the observable fix.

Python already decodes context bytes by UTF-8, then cp1252, then latin-1 in
`metasalmonpy/llm_review.py`; its context parity tests pin cp1252 and the
R Markdown reader. No Python code or parity register change is needed.
