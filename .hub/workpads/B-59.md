## Changes

- `R/configuration.R` owns option defaults and the generated
  `?metasalmon_configuration` / `?"metasalmon-options"` inventory. `.onLoad`
  installs only missing, non-NULL defaults. Existing FALSE values and credentials
  survive loading. An unset timeout stays unset so backend fallbacks remain
  30 or 60 seconds.
- BioPortal's once-per-namespace warning state is private to the package rather
  than a mutation of caller `options()`. No-key retrieval still warns once and
  returns an empty result; an environment key is read at call time.
- Session IDs keep their timestamp/eight-hex shape. A digest of a process-unique
  temporary pathname supplies the suffix without creating a file or consuming
  the caller's statistical RNG. IDs are identifiers, not credentials.
- The reference help, navigation, entrypoint and file map point to one inventory.
  Generated NEWS/index changes contain this new entry only; historical site
  drift was not imported.
